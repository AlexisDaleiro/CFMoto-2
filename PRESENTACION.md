# Guion comercial de ocho minutos

Usar el deployment Preview fijado en ENTREGA-FASE-2.md. Iniciar sesión o preparar un enlace compartido de Vercel antes de la reunión. Abrir la demo en escritorio y tener una ventana de 390 px disponible. No presentar el dominio de producción como si contuviera esta versión.

| Tiempo | Mostrar | Relato |
|---|---|---|
| 0:00–1:00 | Home y primer viewport móvil | “CFMOTO Uruguay es la protagonista. Motos, cuatriciclos y UTV están disponibles desde el primer pantallazo.” Mostrar las tres líneas sin hacer scroll. |
| 1:00–2:00 | Home → Motos → filtro 800 cc | “El catálogo conserva los 27 modelos. El filtro puede compartirse y el historial conserva la selección.” Mostrar filtro y volver atrás una vez. |

| 3:30–4:30 | CFORCE 1000 y ZFORCE 1000 Sport | Cambiar un color de CFORCE. Mostrar que Sport es la variante exacta, no Sport R ni 950. Explicar que las discrepancias están documentadas y los datos dudosos se omiten. |
